# FastNet 0.8.10

运行包 `0.8.10-1`，LuCI `0.8.10-r1`，元包 `0.8.10-22`。OpenWrt IPK/APK 由维护者人工编译，本次发布的是配方所需的上游运行归档。

- 修正共享 LAN 上传速率公式，使用服务器确认字节和浏览器完整耗时，计入准备、排队及回退，避免速率高估。
- 不支持流式请求时复用 Blob；停止、超时不再触发回退上传。独立 LAN 和快速体验继续共享同一模块。
- 千兆和真实 2.5G 已对照原生 iperf。2.5G 网页正常读数 2.36–2.37 Gbps；五次测速（含停止恢复）与 iperf 差异不超过 1.72%。
- LuCI 最低核心依赖同步为 `0.8.10-1`，APK 使用等效的 `0.8.10-r1`。软件中心元包 release 从 21 增至 22。
