# M5 优化 2：直部署权限归一化

末轮审计发现 runtime-policy.json 的内容 SHA256 与 r9 清单完全相同，但现场为 0644，清单却记录开发源文件的 0664。临时测试恢复策略文件时用了正确的安装权限；直部署工具此前照搬开发目录 umask，因此其他源码也可能保留组写位。

修复：所有 root payload 按可执行位统一为 0755/0644，新配置 0600，已有用户配置继续保留。r10 仅规范权限，代码字节与 r9 一致；C helper 与前端哈希不变。正常重启、非 root Gateway/向量及真实 LuCI 均在同一字节版本通过。权限修正后重新审计，并复验实际 Gateway。

包编译/归属/依赖验收继续待人工确认。没有构建新的 IPK/APK。
