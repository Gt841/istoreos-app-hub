# 变更保护兼容标识

软件中心继续使用 optimemachine 这个已安装标识，名称改为“变更保护”，避免出现重复行。它依赖 changeguard 和两个空/薄兼容包，使旧程序和 LuCI 文件能由各自所属包升级退出。

真正后台在 ../changeguard/changeguard。optimemachine 只把旧命令和 init 调用转到 changeguard，不创建第二个服务、登录或页面。没有安装 KAI 时提供 CLI；安装 KAI 后从 KAI 的变更保护入口查看。

历史配置、备份、状态、冻结脚本与用户自定义入口均保留。迁移脚本按已知摘要和链接目标清理旧默认入口，先保存自定义入口，再在旧包回收文件后恢复。不递归删除共享目录或备份目录。
