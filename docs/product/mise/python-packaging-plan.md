# Python pip/venv 与 npm 高级选项实施目标

目标：Python 安装默认准备并验证配套 pip/venv，详情如实显示读取的 pip 版本与 venv 状态；推荐用户在持久分区的独立虚拟环境安装应用依赖；固定 wrap 显式选择目标 venv，避免回退共享解释器，保留私有 GNU 启动路径。npm 默认使用配套版本，独立版本选择放入高级选项。

仍为产品交互原型：不部署设备、不编写生产下载器、不承诺示例状态为实机收据。创建虚拟环境的可下载 wrap 样例属于本轮实施范围；网页本身不创建磁盘目录、不安装 pip 包。

## 任务树

- [x] P1 状态与模型
  - 区分 pip 版本/venv 状态的已知、未读取与设计样例来源。
  - Python 复核与任务包含配套 pip/venv 准备和验证，失败不提交。
  - pip 不提供版本选择；拒绝独立 pip 版本请求。
  - Node 默认 npm 根据 Node 版本匹配，保留高级兼容选择。
- [x] P2 安装与详情
  - Python 安装提示“包含配套 pip，支持虚拟环境”。
  - 详情只读展示实际回传版本和状态，不能用固定文案伪造真实验证。
  - npm 控件默认收起，当前配套版本始终可见。
- [x] P3 使用交互
  - 保留解释器/配套 pip 版本查询。
  - 可填写 /mnt 下应用目录，生成创建 venv、安装 requirements、运行与 shell 命令。
  - 校验路径，提示候选目录不覆盖、应用包与公共 SDK 隔离。
- [x] P4 wrap
  - --create-venv、--venv、已激活受管理 venv 的正确路由；不支持时明确失败，不能静默回退。
  - 校验本地 venv 与固定 SDK 的归属、解释器及 prefix；不创建中央应用登记。
  - 通过统一 SDK 启动器保留 GNU loader；pip、venv python 子进程仍使用同一入口。
  - 缓存与临时目录持久化，禁止把默认安装落到共享 SDK 或用户 site-packages。
  - 不覆盖既有目录，失败仅清理本次创建的候选；命令 stdin/参数不丢失。
- [x] P5 验收与交付
  - 类型、模型、脚本沙箱、可用的真实本机 CPython 离线 smoke、浏览器流程与六语言/宿主回归。
  - 手机深浅主题、复制/下载、错误/未知状态、npm 默认与高级选择。
  - 最多三轮，保留每轮证据；5180 更新预览，记录真实设备/GNU 运行库边界。

## 验收约束

1. 所有核心路径和已有六种语言保持可用，QuickStart 复制源码不变。
2. 页面不执行真实包安装；测试不访问 PyPI，不改宿主 Python，不写 /root。
3. 真实 CPython smoke 与假解释器测试必须分开说明，不能当成 x86/ARM 固件验收。
4. 未通过的项保留未完成，不以最多三轮为理由误报通过。
