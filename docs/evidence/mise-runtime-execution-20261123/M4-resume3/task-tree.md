# M4 续作任务树与验收标准

1. 定位与回归：真实旧 helper 在模拟不响应的可选网络命令下应重现启动等待；新 helper 应在一秒级测试中完成初始化。
2. 修复接入：环境准备无网络；本地 exec/版本/shell 不依赖 KSpeeder；明确安装/升级/远端查询按开关走 ks-cli，保留参数/stdin/退出码和显式镜像。
3. 真实构建：双架构各五个正式 IPK，所有 feed 来源/固定提交、SDK、补丁摘要、载荷、注册、依赖审计通过；安装后字节与候选相符。
4. 设备验收：故意阻塞可选 wget/curl 后真实入口仍可执行；真实 ks-cli 计划显示下载校验保留；实际旧 Node 默认和业务健康不变；普通 UID 固定 wrap、HOME/TMP/npm/子进程通过。
5. 正式页面验收：最终安装包权限/CSRF、副作用边界以及第二 ABI 的安装、刷新、wrap 下载、删除保护、清理通过；保留此前维护/中断恢复与宿主样式证据。
6. 收尾：所有已知临时 rpcd 会话销毁；无安装锁/孤儿工作进程；源码、包、设备状态和回退偏差一致。M4 通过才自动进入 M5。
