# M2 续作通过

用户在首次三次优化失败后授权继续。续作优化 1 完成；未消耗新的第二、第三次优化。首次失败历史见 `../M2/verification.md`。

任务树与标准沿用里程碑 M2.1–M2.7，本轮先修复进程所有权，再补齐原验收缺口，不降低取消、恢复、默认保护及持久存储标准。

## 修复

核心不再用外部 timeout 包装工作命令。每个命令建立独立会话，等待父进程持久保存 boot ID、PID、启动时间、进程组及会话身份后才执行。核心自行轮询截止时间；取消和恢复先停止 worker，再读取所属命令日志，核验身份并收拢会话内进程，最后清理候选、释放锁和发布终态。正常退出也清理遗留后台子进程。旧 boot 的 PID 不参与信号操作，PID 身份改变时保留日志并拒绝误杀。

补齐公共 JSON CLI 的过期计划稳定错误码、默认保护先行和受控 mise 链接清理；不通过 mise uninstall 删除共享 SDK。解包增加重复路径、符号链接父目录写入及链式逃逸检查。

## 双架构结果

两台均通过：35 项存储/下载/运行库/任务/UID 基础集成检查；6 项进程专项；16 项公共 CLI/真实恶意 tar 检查；10 项阶段故障注入，共 67 项。原 timeout 取消回归另行执行，两台 `child_survived=false`。

- `*-integration.json`：源站/强制加速、摘要/缓存、隔离只读/noexec、真实 GNU 库、默认与 UID 等。库输入复用先前已核验缓存，源站/加速小包仍实际下载。
- `*-processes.json`：原失败回归；取消、自然超时、TERM 忽略孙进程、worker SIGKILL、正常退出后台进程、PID 身份保护及提交发布窗口。
- `*-administration.json`：公共 CLI 默认/库删除保护、显式非默认删除、缓存清理、存储根保护、并发和过期计划；六份真实恶意归档均在创建提取目录前拒绝。SDK 元数据夹具明确标 verified=false，不冒充实际 Node 安装。
- `*-faults.json`：准备、下载、解包、探测、已提交五阶段各取消/SIGKILL；旧数据不变，未提交候选清理，提交候选保留，无所属命令残留。
- `*-reboot.json`：两台分别实际 reboot，boot ID 改变，正在运行任务按持久日志恢复为 canceled，旧数据保留，无自动重放。
- `*-post-reboot.json`：分区自动挂载、私有 GNU 库重新验证、无 M2 运行进程；ARM 原有 KSpeeder/AgentFlow 运行且受保护摘要一致。两台内核检查未发现 SquashFS/I/O/OOM 报错。

本机 Lua 语法检查与 git diff --check 通过。源码快照 `candidate-source.tar.gz` 和 `source-sha256.json` 固定本轮候选；后续适配器修改不改变此轮证据所对应的源码。
